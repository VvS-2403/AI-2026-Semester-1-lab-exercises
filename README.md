# AI Lab Exercises

This repository contains the assignments and lab exercises for the AI course (CS-F407). It showcases the process, methodologies, and reproducible results for each exercise.

## Structure

- \1_Search\: State space search algorithms (BFS, DFS, A*, etc.)
- \2_Logic\: Logical reasoning and inference mechanisms
- \3_Agents\: Intelligent agents and environments


Each directory contains:
- The problem statement (PDF)
- \src/\: Source code and implementation
- \
esults/\: Output logs, charts, and metrics
- \README.md\: A detailed walkthrough of the implementation process and how to reproduce the results.
